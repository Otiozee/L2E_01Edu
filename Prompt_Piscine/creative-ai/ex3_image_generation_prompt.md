# Exercise 3: Image Generation Prompt Design

## Prompt 1: Vague Prompt
"A Nigerian city at sunset."

### Model response
The AI produces a generic urban skyline at sunset with little detail about location, style or culture.

## Prompt 2: Refined Prompt
"A vibrant Lagos skyline at sunset, in watercolor style, showing the Lekki Bridge, colorful market stalls along the waterfront, boats in the lagoon, and warm orange-pink skies, viewed from a riverside perspective."

### Model response
The AI generates a highly detailed, culturally rich image: the Lekki Bridge stretches across the lagoon, market stalls add lively colors, boats float in the water, and the sunset reflects beautifully on the scene. The watercolor style adds texture and depth.

## Reflection
The vague prompt gives a generic image. The refined prompt results in a more visually rich, recognizable Nigerian scene with cultural and geographic specificity. So descriptive constraints dramatically improve output quality.
