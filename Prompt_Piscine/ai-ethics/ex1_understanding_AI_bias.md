# Exercise 1: Understanding AI Bias

## Part A – My own try first (no AI)
- Example I thought of: If you ask an image generator "nurse" it shows mostly women, "doctor" mostly men. Or "bride" it show mostly western women in wedding gown because training data comes predominantly from these locations.

- Why bias exists (my words): Datasets come from real world which already has inequalities - more male doctors in photos/news from past decades, so model learns that pattern. Also, if data isn't diverse (e.g., mostly Western faces), it messes up on other groups.

- One mitigation: Balance the dataset - add more examples from underrepresented groups. Or use prompts like "show diverse nurses including men and different ethnicities".

## Part B – Asked AI after: pasted my example + explanation + mitigation, asked what I'm missing.
### AI said: Good start, but also:

- Label bias (humans labeling data wrong)
- Representation bias (not enough samples)
- Aggregation bias (grouping things unfairly)

### Edge cases:
- In healthcare, facial recognition worse on darker skin - misdiagnosis or security fails.
- Hiring: Amazon scrapped tool because penalized women (trained on mostly male resumes).
- Criminal justice: COMPAS tool higher risk scores for Black defendants unfairly.

- My predictions matched some - yeah, hiring and justice are scary because they affect people's lives directly.
