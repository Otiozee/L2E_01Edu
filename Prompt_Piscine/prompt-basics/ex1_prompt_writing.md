## Prompt 2 - question style prompt: "What are the benefits of Python for AI?”
### ChatGpt Output:
Python is popular for AI development due to several benefits:

1. Extensive Libraries: Frameworks like TensorFlow, PyTorch, and scikit-learn make it easy to implement machine learning algorithms.
2. Simplicity and Readability: Python's clean syntax allows developers to write and maintain code efficiently.
3. Community Support: A large community means plenty of resources, tutorials, and pre-built models.
4. Flexibility: It supports various paradigms and integrates well with other languages.
5. Rapid Prototyping: Quick development cycles help in experimenting with AI models.

## Analysis:
The first prompt is super short and to-the-point, like a command. The second one gives more explanation and details, it feels like it's teaching me. Question style pulls out more context, hence it's good for learning.
