# Ethical AI - Quest 00

## What I Learned

This quest showed me that using AI to just copy and paste code makes me finish tasks fast but leaves me with almost zero real understanding. When I forced myself to try first even if my code was messy, then asked targeted questions, I actually remembered things better and felt more confident.


## Main Insight on Ethical AI Use

The ethical way isn't "never use AI" it's "use AI after I've given it my best shot". If I can explain the code without looking at the chat history, then I'm using it fairly. Otherwise, I'm basically cheating myself out of becoming a real developer.


## How I'll Apply This Going Forward

In the next quests, I'll always:

1. Spend at least 15-30 minutes struggling alone before asking anything.

2. Write down what I tried and why it failed before getting help.

3. After getting AI feedback, close the window and rewrite/explain the improved version in my own words.

This way, I will be the one doing the thinking, not the AI.
